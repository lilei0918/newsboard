# NewsBoard — 单页「资讯 + 行情」看板

打开即用的财经看板：**左边筛资讯、中间读新闻、右边看行情**，一屏搞定，不登录、不注册、不需要装任何东西。

```bash
cd ~/Documents/newsboard
./run.sh
```

## 它长什么样

```
┌────────────────────────────────────────────────────────────────────┐
│ 滚动行情条（每 4 秒滚动，点击跳到对应图表，可暂停）                  │
├─────────────┬──────────────────────────────┬───────────────────────┤
│ 筛选         │ 资讯                          │ 行情看板（紧凑 30px）   │
│ · 分类       │ · 分类徽章 + 标题原文          │ · 7 组 44 个代码        │
│ · 搜索       │ · 关键词高亮                  │ · 上行 = 盘中涨跌幅      │
│ · 高亮词     │ · 来源 · 相对时间 · 未读标记   │ · 下行小字 = 盘前/盘后%  │
│ · 14 个资讯源│ · 点击 → 详情浮层              │ · 迷你走势 · K 线浮层    │
│ · 刷新频率   │                              │ · 顶栏「盘中涨跌幅 ↓」排序│
├─────────────┴──────────────────────────────┴───────────────────────┤
│ 状态栏：◀隐藏筛选栏 · 资讯条数/未读 · 行情项数/美股时段 · 5s/轮 · 限流 │
└────────────────────────────────────────────────────────────────────┘
```

* **中文界面，新闻标题保留原文**（关键词高亮用琥珀色）。
* 三栏宽度可拖拽；`Esc` 关浮层；`F5` 立即刷新。
* **状态栏最左边**有「**◀ 隐藏筛选栏 / ▶ 显示筛选栏**」按钮：左栏藏起来后宽度让给资讯列表，
  状态会记住，下次启动保持原样（想找回左栏时按钮一直在状态栏里）。
* 右栏顶栏有「**盘中涨跌幅 ↓**」开关：组内按盘中涨幅从高到低排（红涨在前、绿跌在后），
  再点一下回到配置文件里的原始顺序。行高默认**紧凑 30px**（一屏能看更多行）。
* 行情默认**每 5 秒**刷一轮（左栏可切 3 / 5 / 10 / 30 / 60 秒）。一轮只有 **1 个 HTTP 请求**，
  拿回全部 44 个代码，所以“实时”是真的能撑住，不会把 IP 刷成限流。
* 新闻详情显示源提供的摘要，全文点「在浏览器打开原文」。

## 界面设计（一套统一基线）

参照主流同类程序：**TradingView 自选列表**（数字右对齐 + 等宽数字 + 分组头计数）、
**Feedly / Reeder**（药丸徽章、时间右对齐、未读竖条）、**Linear / Notion**（8px 间距栅格、
低对比描边、只有一个强调色）。

| 项 | 做法 |
|---|---|
| 背景层次 | `#0b0b0d` 窗口 → `#101114` 面板 → `#12141a` 未读行 → `#1a1c21` 悬停，每层只差一点点 |
| 描边 | `#24272d`（细分隔 `#1a1c20`），只用在分隔处 |
| 文字三级 | 正文 `#e9eaec` · 次要 `#9ba2ab` · 最弱 `#6c7278`（时间、单位） |
| 强调色 | 只有琥珀 `#e08b12`；涨 `#f04438` / 跌 `#12b76a`（红涨绿跌，A 股习惯） |
| 字号阶梯 | 状态栏 **10** · 次要 11 · 正文 12 · 标题 13 · 浮层 15（统一像素字号） |
| 数字 | 全部开 **tabular figures**：行情刷新时整列数字不会左右跳动 |

具体到各区域：

* **顶部行情条**：名称（灰）+ 代码（更淡）+ 现价（亮）+ 涨跌幅（红/绿），格间细竖线，点任意一格看 K 线。
* **新闻列表**：分类药丸徽章、未读左侧竖条 + 标题加粗、相对时间右对齐到行尾，行高 68px（一屏约 12 条）。
* **行情看板**：每行「中文别名 + 小号代码」，涨跌幅两行等宽数字，分组头右侧显示标的数量，
  悬停/选中是淡背景 + 琥珀竖条，迷你走势降透明度不抢视线。
* **状态栏**：整条弱化成信息带，字号 10px（比正文小一号）。

## 从 GitHub 克隆后怎么跑

仓库里只放**源码 + 文档**，不放两个体积大、且能随时重新生成的目录：

| 目录 | 体积 | 为什么不在仓库里 | 怎么恢复 |
|---|---|---|---|
| `lib/` | ~150MB | 本机 Qt6 的共享库、动态加载器、Qt 插件，本质是编译产物 | `nix-shell --run 'tools/bundle-runtime.sh'`（或用系统 Qt 跑） |
| `runtime/` | ~256MB | 自带 CPython + yfinance，二进制大且各平台不同 | `tools/setup-runtime.sh` |

所以克隆之后：

```bash
git clone <仓库地址> && cd newsboard
tools/setup-runtime.sh                 # ① 生成 runtime/（yfinance 运行环境）
tools/bundle-runtime.sh                # ② 生成 lib/（Qt 依赖，需要 nix-shell 里跑）
# 或者不用自带库，直接：
nix-shell --run 'cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release && cmake --build build'
./run.sh
```

`tools/setup-runtime.sh` 用系统 Python ≥3.10 建 venv 并装 `yfinance`/`curl_cffi`；
想要像交付目录那样**完全自包含**（目标机器不用装 Python），脚本里也写了
python-build-standalone 可移植 CPython 的做法。

## 目录是自包含的

整个目录可以整体拷到别的机器/别的路径，**不需要安装任何东西**：

| 目录 | 内容 |
|---|---|
| `build/NewsBoard` | 程序本体（Qt6 / C++20） |
| `lib/` | 全部运行库 + 动态加载器 + Qt 插件（不依赖系统 Qt，不依赖 nix store） |
| `runtime/python/current/` | 自带 CPython 3.11，**已内置 yfinance** |
| `scripts/yf_fetch.py` | 行情桥（批量报价 / 迷你走势 / 历史 K 线） |
| `config/` | 用户配置（首次运行生成） |
| `data/` | 缓存、状态日志、yfinance 的 cookie 库（首次运行生成） |

`run.sh` 用 `lib/` 里的加载器 + `--library-path` 启动，并把 `QT_PLUGIN_PATH` 指向 `lib/qt6/plugins`。

配置与缓存默认就放在本目录的 `config/`、`data/` 下（可写、可随目录一起搬走）。想把它们挪走
（例如把缓存丢到 /tmp、或者在同一台机器上跑第二份实例）用环境变量：

```bash
NB_CONFIG_DIR=/tmp/nb/config NB_DATA_DIR=/tmp/nb/data ./run.sh
```

## 行情列表（默认标的）

默认 7 组、**44** 个代码，全部实测可从 Yahoo 取到数据（2026-09 验证）。

| 分组 | 代码 |
|---|---|
| 指数与期货 | `ES=F` `NQ=F` `YM=F` `^SOX` |
| 算力 / 云 / 软件 | `NVDA` `AVGO` `MRVL` `AMD` `NBIS` `ORCL` `CRM` `FTNT` |
| 光模块 / 光器件 | `AAOI` `LITE` `COHR` `GLW` `AXTI` |
| 存储 / 内存 | `MU` `WDC` `SNDK` `KXIAY` `SKHY` |
| 半导体设备 / 材料 / 封测 | `ASML` `AMAT` `LRCX` `KLAC` `TER` `ACMR` `TSEM` `AMKR` `MTSI` |
| 电力 / 能源 / 运输 | `GEV` `VRT` `FRO` |
| 其他权重股 | `META` `GOOGL` `TSLA` `INTC` `TSM` `NOK` `MRNA` `APH` `EWY` `SPCX` |

几点实测结论：

* **费城半导体指数要用 `^SOX`** —— `.SOX` 在 Yahoo 取不到数据。
* `SPCX`（SpaceX）Yahoo 确实有报价（Space Exploration Technologies Corp.）。
* `KXIAY`（铠侠 ADR）、`SKHY`（SK 海力士 ADR）是 OTC 粉单，Yahoo 能正常取；OTC 没有盘前盘后，
  所以不会有右侧那行小字。
* `ES=F` / `NQ=F` / `YM=F` 是期货主连，几乎全天交易，永远显示「盘中」且没有延长时段小字。

### 中文别名

每行的名称位显示的是**中文别名**（在 `src/core/FeedCatalog.cpp` 的 `builtin_quote_aliases()` 里定义），
比 Yahoo 的英文全称好认。别名可改，也可留空（留空则回退 Yahoo 名称）；改完写进
`config/config.json` 的 `quote_aliases` 字段即可覆盖内置值。悬浮提示里会同时给出
「别名 · Yahoo 名称」。

### 增删标的

编辑 `config/config.json` 的 `quote_groups`（或直接改 `src/core/FeedCatalog.cpp` 里的
默认值后重编译）。注意 `Config::load()` 是**按分组 id 合并**的：文件里出现的 id 会覆盖
该组的 symbols，没出现的 id 沿用内置默认。

## 涨跌配色与时区/时段

* **红涨绿跌**（A 股习惯），K 线同色。改配色只需动 `src/ui/Theme.h` 里的 `up()` / `down()`。
* **每行只有涨跌幅，不显示任何价格**（盘中价、盘后价都不显示）：
  上行大字 = **盘中涨跌幅**（常规时段口径，**排序也按它**），
  下行小字 = **盘前/盘后涨跌幅**（没有延长时段数据时该行留空）。
  这样一到盘后，屏幕上不会只剩盘后那零点几个点、把当天真实涨跌盖掉；
  要看具体价格，鼠标悬浮有 昨收/盘中/盘前/盘后 四个价格，点开还有 K 线。

  | 下行小字 | 什么时候出现 | 涨跌幅基准 |
  |---|---|---|
  | 盘前涨跌幅 | 该标的正在盘前交易 | 盘前价 vs **上一交易日收盘** |
  | 盘后涨跌幅 | 正在盘后，或盘后刚结束（夜里看到的就是它） | 盘后价 vs **当日正式收盘** |

* 状态栏的「美股 盘前/盘中/盘后/收盘」以标普 500（`^GSPC`）的 `marketState` 为准。
* 判定用的是**交易所自己公布的时间窗**（`currentTradingPeriod`，带交易所时区），
  夏令时、半日市都会自动正确；比较的是绝对时刻，所以本机时区 +08:00 也不影响判断。
* 加密与外汇连续交易，没有延长时段小字；A 股/港股/OTC 在正式时段外不显示小字（那行留空）。
* 鼠标悬停在某行会列出**昨收、盘前、盘中、盘后**四个价格及各自涨跌幅、**数据新鲜度**，
  以及**数据源**（`Yahoo` / `新浪实时`）；已知延迟的品种会写明原因。
* 券商若提供**隔夜时段**（美东 20:00–04:00，Blue Ocean ATS 等），那部分 Yahoo 不提供，
  小字显示的是 20:00 ET 的盘后收盘价（提示里有确切数据时间）。

## 数据来源

**资讯**：**14 个源**——财联社 + 13 个实测「更新快、信息密度高」的英文源（彭博市场、
CNBC 财经、CNBC 世界、Seeking Alpha、Investing.com、FXStreet、Benzinga、TechCrunch、
CoinDesk、CoinTelegraph、Decrypt、OilPrice、The Guardian World）。中文只保留财联社；财联社没有官方 RSS、
网页是前端异步渲染，所以走它自己的签名接口（`sign = md5(hex(sha1(sorted_query)))`，
用 Qt 自带的 SHA1/MD5 实现）。

> 曾经收录过 45 个源，但其中大半是官方机构稿（美联储 7440 分钟才一条）、周更或已失效的源，
> 留着只会占满列表、让人误以为“没在更新”，所以**全部删除**（不是置灰，是彻底移除，
> 界面上不会留下勾选项）。默认源可以在左栏按需勾选关掉。
>
> 选源标准不只是“接口通不通”，还要看**内容有没有在更新**：例如 WSJ 的 markets feed
> 接口返回 200 但 `last-modified` 停在 2025-01-27，条目日期全是 20 个月前，属于僵尸源，
> 已被剔除换成 The Guardian World。

**行情**：yfinance（自带解释器里已装好），走 Yahoo 的**批量报价接口**
`v7/finance/quote`（cookie + crumb 用 `curl_cffi` 伪装浏览器取）：
* **一轮 = 1 个 HTTP 请求**拿回全部代码（44 个实测约 0.3 秒），响应里直接带
  `marketState / preMarketPrice / postMarketPrice / regularMarket*`，盘前盘后不用自己推。
* 因此默认 **5 秒**一轮成为可能（约 720 次/小时，远低于限流阈值）。
* `scripts/yf_fetch.py` 以**常驻守护进程**方式运行（`yf_fetch.py daemon`，JSON 行协议），
  省掉每轮 1.5~2 秒的解释器启动；守护进程异常退出会自动重启，并在重启前退回一次性脚本兜底。
* 迷你走势：5 天 / 1 小时收盘序列，5 分钟一次；历史 K 线：点开图表时按需拉取（也走守护进程）。

**⚠ 美股指数期货的 10 分钟延迟（已解决，记下来免得再踩）**
Yahoo 对 **CME / CBOT 的期货**只提供**延迟 10 分钟**的数据：`ES=F` 的
`regularMarketTime` 恒比当前时刻早 10.0 分钟，而 `marketState` 却报 `REGULAR`
（看起来“在交易但数字不动”）。这**不是本程序的刷新问题**——换 `v8/finance/chart`
的 1 分钟线同样是滞后 10.0 分钟，是交易所授权所限。

解法：期货改用**新浪外盘期货接口**（`hq.sinajs.cn/list=hf_ES,hf_NQ,hf_YM,…`，实时，
时间戳与本地时钟同秒，**昨收字段与 Yahoo 完全一致**），在 `yf_fetch.py` 里做替换：
* 只对「Yahoo 报常规时段 + 时间戳滞后 > 60 秒」的期货品种生效；
* 有安全阀：新浪与 Yahoo 的**昨收差异必须 < 0.3%**，否则认为不是同一合约月份，
  保留 Yahoo 数据并标记 `delayed`；
* 拿不到实时源时如实标记 `delayed`，悬浮提示会写明「Yahoo 对 CME/CBOT 期货延迟 10 分钟」。

实测：`ES=F` 由滞后 10.04 分钟变为 **0.2 分钟**，状态栏会显示「期货实时源」。

**防封**：一轮一个请求 + 1.5 秒最小间隔 + 上一轮未完成不发下一轮 + **429 冷却 120 秒**
（识别到限流立即停止发请求，到期自动恢复）+ 非限流连续失败 3 次退避 60 秒。
出问题时看 `data/quote_status.log`。

## 加入启动器（Walker）

已注册到 Walker（以及各类应用菜单）。装/重装/目录搬动后修正路径：

```bash
tools/install-shortcut.sh
```

它会写 `~/.local/share/applications/newsboard.desktop`，图标取 `assets/newsboard.svg`。
Walker 里搜 **newsboard**、**market**、**quotes** 都能出来（已用 `elephant query` 验证）。
你系统语言是 en_US，所以显示名是 `NewsBoard`；切到中文语言会显示「NewsBoard 资讯行情看板」。

## 常用命令

```bash
./run.sh              # 启动
./run.sh --selftest   # 行情自检：报价/迷你走势/历史K线，打印结果后退出
```

排查行情看 `data/quote_status.log`；左侧「修复行情运行环境」按钮只在
`runtime/` 缺失时出现（用自带 pip 重装 yfinance，需联网）。

## 排查界面问题（截图模式）

```bash
NB_SHOT=/tmp/x.ppm NB_SHOT_DELAY=12000 ./run.sh
```

启动后等 12 秒把窗口渲染成图片再退出（`.ppm` 是无压缩格式，方便脚本做像素分析；
也可以写 `.png`）。报界面问题时附一张图最省事。

## 已知边界

* 只做「看」：不登录、不下单、不做组合管理。
* 新闻详情是摘要而非正文；要全文点原文链接。
* 界面交互（点击/浮层/图表切换）未做过自动化验证，遇到问题请反馈。

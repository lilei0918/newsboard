# 列重叠问题：修复前后对比

问题：右栏行情里，**迷你走势图（分时图）与涨跌幅数字画在了同一片区域**，视觉上叠在一起。

## 原因

两个列各算各的坐标，没有从同一边（右边缘）统一排布：

| | 旧代码的 x 范围 | 结果 |
|---|---|---|
| 迷你走势 | `[1263, 1319]` | 与涨跌幅列重叠 **53px** |
| 涨跌幅 | `[1267, 1325]` | 被走势线穿过 |

## 修复

所有列改为**从右边缘往左依次排布**，并留固定间距（`kColGap = 10`）：

现价 `[1327,1403]` ← 涨跌幅 `[1253,1316]` ← 10px 空隙 `[1243,1252]` ← 迷你走势 `[1187,1242]` ← 名称（占剩余空间）

实测（在交付构建的截图里量像素）：走势墨迹 `[1193,1239]`、涨跌幅墨迹 `[1275,1316]`，**相距 36px，完全不重叠**。
另外窄面板时若留给名称的空间不足 70px，会自动不画走势，避免把名称挤没。

## 文件

* `1-修复前-走势与涨跌幅重叠.png` —— 修复前（截自旧构建）
* `2-修复后-列不再重叠.png` —— 修复后

两张图都是从同一尺寸窗口（1421×1026）截的右栏区域，可直接横向对比。

# 行情口径改造：盘中涨跌幅恒为主行 + 盘前/盘后小字（2026-09-17）

需求：① 盘中涨跌幅任何时段都必须在列表里；② 排序按盘中涨跌幅；③ 盘前/盘后的行情在合适位置以小字显示。

## 改动

* 主行（现价 + 涨跌幅）**恒为盘中口径**（`regular_price` / `regular_change_percent`），
  排序、红涨绿跌配色也都用盘中；过去盘后时段主行会显示盘后那零点几个点，把当天真实涨跌盖掉。
* 盘前 / 盘后的行情以小字画在同一行（现价左侧）：`盘后 215.68 +0.83%`，
  标签灰、价格灰、涨跌幅红涨绿跌；正在盘中时不显示（此时接口里的盘前/盘后字段是上一场的残留）。
* 列布局优先级重排为：**现价+盘中涨跌幅 → 小字 → 名称 → 迷你走势**，
  右栏默认宽度 420 → 560px，行高默认紧凑 26px。

## 实测像素（交付构建，1560×940）

| 列 | 墨迹区间 | 说明 |
|---|---|---|
| 名称 | `[1010,1079]` | 中文别名 |
| 迷你走势 | `[1183,1239]` | 红色走势线 |
| 盘前/盘后小字 | `[1306,1380]` | 标签 `[1306,1323]` + 价格 `[1326,1347]` + 涨跌幅 `[1350,1380]` |
| 盘中涨跌幅（主行） | `[1411,1455]` | 红涨 |
| 盘中现价（主行） | `[1509,1541]` | 白色 |

全部列对间距 ≥ 20px，**0 处重叠**；窄窗口（798px）下同样 0 重叠，小字会自动降级为
`盘后 +0.83%`（省掉价格）以保住名称列。

截图见 `3-盘后小字与5秒实时档.png`。

# 只看涨跌幅 + 左栏可隐藏 + 期货实时源（2026-09-17 第二轮）

## 1) 行内不再显示任何价格，改成两行涨跌幅

需求：取消个股的「盘后」文字、盘后价格、盘中价格，把**盘后涨跌幅放到盘中涨跌幅下面**。

* 上行大字 = **盘中涨跌幅**（主口径，排序也按它）
* 下行小字 = **盘前/盘后涨跌幅**（没有延长时段数据时该行留空），不带任何文字标签
* 价格全部移出列表（要看就去悬浮提示或 K 线）：悬浮提示里仍有 昨收 / 盘中 / 盘前 / 盘后 四个价格
* 行高随之从 26px 调到 **30px**（两行文字放得下）

实测像素（1552 宽右栏，涨跌幅列右对齐到 x≈1542）：

```
   y  91 ··························████·······████··██████··████··███·····   ← 盘中涨跌幅（大字）
   ...
 253 ·····································███····████·████████·██·····      ← 盘后涨跌幅（小字）
```

逐行结构校验：31 行里**最右侧一段是彩色涨跌幅 28 行、灰白价格 0 行** —— 价格列已彻底移除；
左半部分每行只有 1~2 段（名称 / 名称+迷你走势），没有多余列。

## 2) 左栏可以隐藏/显示

状态栏最左边加了「**◀ 隐藏筛选栏**」按钮（隐藏后变成「▶ 显示筛选栏」，按钮在状态栏里永远点得到）。
隐藏时宽度让给资讯列表，状态写进配置，下次启动保持。

实测：左栏显示时竖直分隔线在 `x=240` 与 `x=999`（三栏）；隐藏后只剩 `x=999` 一条，
新闻区最左墨迹从 `x=240` 变成 `x=0`，而行情栏位置不变。

## 3) 美股指数期货“10 分钟前的数据”——根因与修复

**根因：Yahoo 对 CME / CBOT 期货只给延迟 10 分钟的数据**，不是本程序的刷新问题：

| 检查 | 结果 |
|---|---|
| `v7/finance/quote` 的 `regularMarketTime` | 恒比当前时刻早 **10.04 分钟**（`ES=F` / `NQ=F` / `YM=F`） |
| `v8/finance/chart` 的 1 分钟线最后一根 | 同样早 **10.01 分钟**（换端点无用） |
| `marketState` | 却报 `REGULAR`（所以看起来“在交易但数字不动”） |

**修复**：期货改用**新浪外盘期货接口**（`hq.sinajs.cn/list=hf_ES,hf_NQ,hf_YM,…`，实时），
并加安全阀（新浪与 Yahoo 的昨收差异必须 < 0.3%，否则视为不同合约月份、保留 Yahoo 并标记延迟）。

实测：`ES=F` 滞后 **10.04 分钟 → 0.21 分钟**，状态栏显示「期货实时源」。
`^SOX`（指数，非期货）与美股个股仍走 Yahoo。

截图见 `4-两行涨跌幅与实时期货.png`。

# 界面精修：统一设计基线（2026-09-17 第三轮）

参照主流同类程序：**TradingView 自选列表**（数字右对齐 + 等宽数字 + 分组头计数）、
**Feedly / Reeder**（药丸徽章、时间右对齐、未读竖条）、**Linear / Notion**（8px 间距栅格、
低对比描边、只有强调色是彩色的）。

## 设计基线

| 项 | 做法 |
|---|---|
| 背景层次 | `#0b0b0d` 窗口 → `#101114` 面板 → `#12141a` 未读行 → `#1a1c21` 悬停（每层只差一点） |
| 描边 | 常规 `#24272d`，细分隔 `#1a1c20`；只用在分隔处，不用来包边 |
| 文字三级 | 正文 `#e9eaec` / 次要 `#9ba2ab` / 最弱 `#6c7278`（时间、单位） |
| 强调 | 只有琥珀 `#e08b12` 一个强调色；涨 `#f04438`、跌 `#12b76a`（红涨绿跌） |
| 字号阶梯 | 状态栏 10 / 次要 11 / 正文 12 / 标题 13 / 浮层大标题 15（**统一像素字号**） |
| 数字 | 全部开 **tabular figures（tnum）**：刷新时整列不会左右跳 |

## 各区域改动

* **顶部行情条**：一格拆成「名称（次要灰）+ 代码（最弱灰）+ 现价（亮色）+ 涨跌幅（涨跌色）」，
  格与格之间用细竖线；高度 30 → 34px 与右栏顶栏对齐。实测相邻格间距稳定 28px，无重叠。
* **新闻列表**：行高 62 → 68px；分类做成**药丸徽章**（原来是 `[分类]` 方括号文字）；
  未读用**左侧 3px 竖条** + 标题加粗（不再整行变色）；**相对时间右对齐**到行尾；
  标题/正文两行行高 18px。实测：竖条列 241–243，标题墨迹 19px（含徽章）、元信息 11px，
  时间右对齐到 x=975（列表右边界 991）。
* **行情看板**：每行显示「中文别名 + **小号代码**」（代码紧贴别名，不再贴到列右侧留一大段空白）；
  涨跌幅两行都用等宽数字，上行半粗、下行小号；分组头右侧加**标的数量**（右对齐到列尾 x≈1541）；
  悬停/选中统一成淡背景 + 琥珀左侧竖条；迷你走势线条降低不透明度，不抢涨跌幅的视线。
* **左栏**：头部改成与中栏同一套（标题 + 灰色副标题 + 1px 分隔线）；滚动区底色补齐为面板色
  （此前漏出更深的窗口底色，三栏不像同一个平面）；下拉框、输入框、芯片统一暗色圆角。
* **浮层**：圆角 8px、正文区圆角 6px、标题 15px/22px 行高、说明文字用次要灰。
* **状态栏（按要求变小）**：字号 13 → **10px**。实测文字墨迹高度 **14px → 11px**。
